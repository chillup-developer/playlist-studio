# โลโก้ ชื่อช่อง / URL กลุ่ม สถานะ การจัดการ
ยังไม่มีช่องในเพลย์ลิสต์นี้ — กด "+ เพิ่มช่อง" หรือ "📥 นำเข้า" เพื่อเริ่มต้น

เพลย์ลิสต์ของฉัน

สตรีมได้รับการเข้ารหัสและโหลดเข้า RAM เท่านั้นเมื่อเล่นในแอป Chillup IPTV

ชื่อเพลย์ลิสต์ รหัส Redeem จำนวนช่อง วันหมดอายุ อัปเดตล่าสุด จัดการ
ยังไม่มีเพลย์ลิสต์ที่คุณบันทึกไว้

⚙️ ตั้งค่า Google OAuth Client ID

สาเหตุของ Error 401: invalid_client:
เนื่องจากยังไม่มีการระบุ Google Client ID จริงของคุณ คุณสามารถกรอก Client ID ได้ด้านล่าง หรือเข้าสู่ระบบด้วยชื่อและอีเมลด้านบนได้ทันทีโดยไม่ต้องตั้งค่าใดๆ
คัดลอก Client ID จาก Google Cloud Console มาวางที่นี่
📋 วิธีสร้าง Google Client ID (ทำครั้งเดียว):
  1. ไปที่ Google Cloud Console > Credentials
  2. กด Create Credentials > OAuth client ID
  3. เลือก Application type: Web application
  4. ในช่อง Authorized JavaScript origins ให้ใส่ URL เว็บไซต์ของคุณ (เช่น URL GitHub Pages)
  5. กด Create แล้วนำ Client ID มาวางในช่องด้านบน
